2026-07-27 · 본 보고서는 전적으로 v4 라운드에 기반한다: EOS 경계 수정 후 mask 백본 7개 전체를 재학습하고, 그 위에서 모든 판별자와 평가를 다시 수행했다. 기존 통합 보고서(RESULTS_BD.pdf)는 수정 전(v2) 백본의 기록으로 보존되며, 여기서는 수정 전/후 비교의 "이전" 측으로만 인용한다. 네이밍: v4 산출물은 전부 _v4 태그를 가진다 — 체크포인트 BD_porto_v3_normal_mask_blk{B}_v4_bd.pth (v3는 데이터셋 인덱스 porto v3-0.05이며 모델 라운드가 아님), disc BDdisc_*_v4.pth, pool *_pool_v4_*, 평가 태그 v4m*/v4f01m*.

1. EOS 경계 수정

학습 캔버스는 [dst, v0, …, vL-1=dst, END…END | PAD…]이고, END는 dst가 속한 블록의 남은 자리에만 채워지며 이후 블록은 PAD(loss 제외)다. 이 스펙에서 dst가 블록 경계에 정확히 떨어지는 샘플은 END 감독이 0이 된다 — 전체 데이터의 1/B 비율이고, B=1이면 모든 샘플이다. 그래서 v2 blk1 백본은 종료를 전혀 학습하지 못했다: unconditional 생성의 100%가 캔버스 캡(길이 101)까지 발산했고 edge의 50.5%가 invalid, valid rate 0.000. B≥2에서는 같은 결함이 경계 종료 길이의 체계적 결핍으로 나타났다: (L+1) mod B = 0인 생성 길이 비율이 실제의 절반 수준(blk2 0.234 vs 0.500; blk32 0.011 vs 0.027).

수정 (bd_models.py build_canvas()): END tail이 비게 되는 경우 캔버스를 한 블록 연장하고 그 블록 전체를 END로 채워 loss에 포함한다. 이제 모든 샘플이 END target을 ≥1개 학습하며, B=1은 샘플마다 정확히 1개다. smoke_test_bd.py로 검증(캔버스 스펙, 두 커널의 forward/backward·플래닝).

blk64는 구조적으로 불변: 이 데이터셋에 L=63/127인 경로가 사실상 없어(경계 비율 ≈ 0.000) 수정이 blk64 학습 샘플을 하나도 건드리지 않고, 고정 시드 학습이라 v4 blk64는 v2와 동일한 수치를 재현한다. 완전성을 위해 유지한다.

2a. 길이 분포와 edge 분포 일치도 (JSEV)

블록당 동일한 생성 20,000개를 전체 실제 NORMAL 집합(최단경로 1,930,710개 — 참조 행)과 비교. KS는 생성/실제 길이 분포 간 Kolmogorov–Smirnov 거리. JSEV는 프로젝트 표준 edge 분포 지표(utils/evaluate_new.py::Evaluator.calculate_divergences)로, 전체 V × V 격자에서 실제/생성 방향 edge 빈도 분포 간 Jensen–Shannon divergence이며 단위는 nats다(scipy rel_entr; ln 2로 나누면 bits). R²는 동일한 평탄화 edge 분포에서 계산하고, Spearman ρ는 edge 빈도의 순위 상관으로 masked(실제 빈도가 0이 아닌 칸) / 전체 칸 순으로 보고한다. JSEV는 낮을수록, R²·ρ는 높을수록 좋다.

  • edge 분포의 RMSE / MAE도 같은 순서를 따르며(blk1 2.83e-06 / 8.48e-08 → blk64 8.23e-06 / 2.38e-07) sets_res/uncond_jsev_v4.json에 기록되어 있다.

2b. Unconditional EM/PC — 각 샘플의 양 끝점을 자신의 OD로

EM/PC는 주어진 OD가 필요 없다: evaluate_em_pc는 생성 경로 자신의 (start, end)를 OD로 삼아 참조 최단경로 데이터에서 조회한다. 학습 데이터가 최단경로이므로 uncond EM = "샘플이 자기 양 끝점 기준 최단경로인가" — 분포 충실도 지표다. OD 커버리지(생성된 OD가 참조에 존재하는 비율)는 전 블록 ≈1.0이라 측정이 깨끗하다. 블록당 3,000개, seed 7. novel∧EM이 합성 데이터의 화폐: 알려진 OD의 새로운 최단경로, 즉 데이터셋에 없는 등장(等長) 대안 경로.

2c. Valid 생성물의 다양성 — 직관 검증

원시 novelty는 블록과 함께 상승한다(0.406 → 0.973; 블록 내 mean-field 샘플링의 조합 다양성) — 그러나 invalid 경로의 다양성은 노이즈다. valid 부분집합으로 제한하고 동일 크기 실제 표본과 비교(지표: distinct-OD 비율, 사용된 고유 edge 수, edge 사용 Shannon 엔트로피, edge 집합의 평균 pairwise Jaccard 유사도 — 높을수록 서로 비슷). n valid는 그 부분집합의 크기다 — 생성 20,000개 중 모든 edge가 합법인 개수이자 각 행이 계산된 표본 수.

5. 공개 베이스라인과의 통제 비교: D-CBG (Schiff et al.)

Simple Guidance Mechanisms for Discrete Diffusion Models의 플러그인 이식(dcbg_plugin.py, 그들의 _cbg_denoise 로직 그대로)을 v4 백본에서 재실행. IW와 다른 점은 방법론 고유의 차이뿐: D-CBG는 노이즈 상태 pφ(y | xt, t)를 채점해 위치별 categorical을 틸팅하고, IW는 clean 부분경로를 채점해 joint 후보를 재가중한다. 나머지는 모두 통제 일치 — 동일한 인접행렬 인지 아키텍처(-adj 1), 동일한 1% 데이터 예산·split seed, 동일한 model-negative(각 블록 자신의 v4 unconditional pool을 모델 forward process로 노이즈 처리), 동일한 except_0 예약 1,000쌍, seed 7.

양쪽 모두 γ = 1. 이전 라운드는 D-CBG만 γ = 4, IW는 기본값 γ = 1이라 서로 다른 강도에서 비교한 셈이었다. 여기서는 둘 다 tempering 없는 정확한 형태다 — IW의 wn = exp(γ·ℓφ)는 밀도비 D/(1−D) 그대로가 되고, D-CBG의 log pθ + γ·log pφ는 Bayes 틸트 그대로가 된다. (참고로 v2 백본에서의 v1-era γ 스윕: D-CBG blk4 valid γ=1/2/4에서 0.262 / 0.273 / 0.289 — 이 방법은 γ ≫ 1이라야 움직인다.)

exact vs first-order는 동일 분류기에 대한 런타임 플래그(-approx)이지 별도 모델이 아니다. exact: reveal 위치에서 V = 1,393개 토큰을 전수 열거 — first-hitting에서는 스텝당 그 한 자리만 소비되므로 근사가 아니라 정확하다. first-order: 그들의 Taylor 변형, reveal당 one-hot 입력에 대한 forward+backward 1회.

5.6 실행 시간과 채점 호출 수 — 동일 조건 측정

타이머가 정확히 재는 것: OD 쌍 100개짜리 배치에 대한 플래너 호출 1회의 wall-clock — (origin, destination) 리스트를 넘긴 시점부터 완성된 정점 경로를 돌려받는 시점까지 — 을 100으로 나눈 값이다. 포함: denoiser forward, guidance 채점(판별자/분류기), 후보 샘플링, reveal별 bookkeeping, 플래너 자체의 CPU sync·정지 스캔, 경로 조립. 제외: 체크포인트/데이터 로딩, P1/P3 후처리, EM/PC/DTW 채점, 그리고 플래너가 반환한 이후의 모든 것. 따라서 이 값은 100경로를 동시에 계획할 때의 경로당 분할 비용이며, 경로 하나를 단독으로 계획할 때의 지연이 아니다(그 경우 GPU 활용도가 낮아 경로당 비용은 훨씬 커진다).

공정성 통제(time_guidance.py): 모든 방법에 대해 동일 OD 쌍·동일 배치·동일 시드; 한 번에 한 방법씩 순차 실행, 스크립트가 유휴임을 확인한 GPU 하나에서만 — nvidia-smi로 상주 compute 프로세스를 조회하고 하나라도 있으면 실행을 거부한다; (블록, 방법) 칸마다 warm-up 배치를 1회 실행하고 버려서 CUDA 컨텍스트 생성과 커널 오토튜닝이 보고 수치에 절대 섞이지 않게 했다; 모든 측정 구간은 torch.cuda.synchronize()로 감쌌다; 그리고 칸마다 예약 풀의 서로 다른 슬라이스 3배치(쌍 1–100, 101–200, 201–300)를 측정하며 이는 방법 간 동일하다. 그 3배치의 평균 ± 표준편차로 보고하므로, 산포는 실행 간 지터뿐 아니라 배치 구성 차이도 반영한다. 칸당 300경로, 총 35칸.

7. 판별자 유효성 (요약)

전체 분석은 DISC_VALIDITY_KO.pdf / DISC_VALIDITY.pdf. 요지: (i) seen/unseen disc는 held-out 입력에 거의 동일한 점수를 매긴다(logit Pearson 0.81–0.98); (ii) model-negative 과제의 zero-shot AUC 손실은 양방향 probe 모두 ≤0.05 — 판별 신호의 대부분(입력 인접행렬 대비 edge 합법성, 모델 artifact)이 구조적으로 시나리오-무관; (iii) 더 어려운 data-negative probe(real vs real)가 두 학습 방식을 가른다: 단일 시나리오 e0 disc는 zero-shot에서 AUC −0.100(fam 0.05)/−0.084(fam 0.1) 하락, 99-시나리오 e99 disc는 거의 평탄 — 시나리오 고유 정보의 일반화는 다중 시나리오 학습이 만든다; (iv) v2 blk1의 "최고 AUC"는 퇴화 negative pool의 산물이었고 EOS 수정 후 소멸(0.985→0.870) — negative pool 교란 분석의 확증.
